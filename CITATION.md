# Attribution

Suggested acknowledgment:

> Binary Mask Analyzer contributors. Binary Mask Analyzer, version 0.1.0.

When an original public repository URL is available, include its link with this
acknowledgment. No DOI or public repository URL has been assigned in this
package. Do not invent one. If using a modified version, also identify the
version or changes used.

Use a README, documentation, credits section, or equivalent accessible place
for software attribution. For publications substantially using the software,
include an acknowledgment in the methods, software, or references section.
Retain the copyright notice and [LICENSE](LICENSE) when redistributing copies
or substantial portions. There is no requirement to report each use or obtain
separate approval. These attribution requirements concern the software; they
do not establish permission to use any input dataset.
